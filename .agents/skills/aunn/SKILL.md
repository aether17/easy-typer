# aunn

This project keeps its stories and bugs (items) in aunn. Before working with items, run `aunn guide` and follow the usage it prints; it matches the aunn version installed on this machine.

If the `aunn` command is not found, tell the user to install it and set it up once on this machine:

```sh
curl -fsSL https://aunn.mashiro.cafe/install.sh | sh
aunn setup
```
